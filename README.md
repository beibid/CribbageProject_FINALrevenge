# Cribbage Royale

Videojuego multijugador de Cribbage para dos jugadores, desarrollado como proyecto final de Tecnologías para la Construcción de Software en la Facultad de Estadística e Informática de la Universidad Veracruzana.

## Tecnologías
- C# con .NET Framework 4.8
- WPF para el cliente
- WCF (NetTcpBinding) para la comunicación cliente-servidor
- Entity Framework 6 y SQL Server
- Serilog para el registro de bitácora
- MSTest y Moq para las pruebas
